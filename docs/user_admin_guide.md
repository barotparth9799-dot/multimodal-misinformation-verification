\# User and Administrator Guide



\## 1. Purpose



This guide explains how to install, run, use, test, and maintain the Multimodal Misinformation Verification system.



The system accepts a textual claim and an associated image and produces a multimodal verification result using evidence retrieval, image-text consistency analysis, NLI, and multimodal fusion.



\---



\## 2. System Requirements



Recommended environment:



\- Windows 10/11 or compatible operating system

\- Python 3.11

\- At least 8 GB RAM

\- Internet connection for initial package/model setup

\- Sufficient disk space for Python packages and AI models



The current development environment uses Python 3.11.9.
